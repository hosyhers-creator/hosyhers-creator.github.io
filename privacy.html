隐私说明

适用于 hosyhers-creator 维护的 YouTube Uploader 本地频道上传工具。更新日期：2026-11-17。

访问与使用

工具通过 Google OAuth 获取用户同意的 youtube.upload 和 youtube.readonly 权限，读取频道名称、ID 及视频状态；按用户指令将视频、标题、描述和封面发送给 YouTube。Google 密码在 Google 登录流程中输入，本地脚本不要求保存密码。

存储和保留

授权令牌保存在运行脚本的电脑；工具可能保留任务清单、素材路径、上传结果和状态记录。当前没有自动删除周期，文件保留至用户或指定操作人员手动删除。用户应自行保护电脑与备份。

数据共享

执行上传和查询所需的数据会发送给 Google/YouTube。拥有者明确同意后，可把包含刷新令牌、频道身份和封面检查报告的授权 ZIP 私下交给指定同事；ZIP 本身未加密，令牌持有人可在已授权范围内操作频道。不要公开交接包。

本地脚本不包含将上述数据出售、用于广告定位或训练通用 AI 模型的功能。如果另行使用 Codex 或其他助手处理资料，该服务的数据处理受其自身政策与组织设置约束。使用本工具取得的 Google 用户数据应遵循 Google API Services User Data Policy，包括 Limited Use 要求。

撤销和删除

可以在 Google 第三方连接撤销本应用授权。要删除本地记录、素材或授权副本，请删除相应文件和备份，并联系接收授权的指定同事删除其副本。撤销授权不会自动删除已上传的 YouTube 视频；需在频道中单独处理。

网站与联系

说明网站使用 GitHub Pages 托管，访问请求由 GitHub 按其隐私政策处理；页面没有自行加入分析脚本、登录表单或视频收集功能。一般问题可通过 项目反馈联系维护者；涉及私密数据的请求应通过与维护者或指定同事已有的私下渠道沟通，不要在公开反馈中提交敏感内容。
