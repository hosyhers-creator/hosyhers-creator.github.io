隐私说明

适用于 hosyhers-creator 维护的 YouTube Uploader 本地频道上传工具。更新日期：2026-11-17。

访问与使用

工具通过 Google OAuth 获取用户同意的 youtube.upload、youtube.readonly 和用于修改视频信息的 youtube.force-ssl 权限（Google 的该权限范围还包含视频及评论的查看、编辑、删除能力），读取频道名称、ID 及视频状态；按用户指令上传视频、修改指定视频标题和描述、更换封面，并将所需数据发送给 YouTube。Google 密码在 Google 登录流程中输入，本地脚本不要求保存密码。

存储和保留

授权令牌保存在运行脚本的电脑；工具可能保留任务清单、素材路径、上传结果和状态记录。当前没有自动删除周期，文件保留至用户或指定操作人员手动删除。用户应自行保护电脑与备份。

数据共享

执行上传和查询所需的数据会发送给 Google/YouTube。拥有者明确同意后，可通过限时授权邀请将频道权限交给指定同事的本机工具。该授权服务由 Sites 托管，在服务器内存中短暂处理 Google 授权码及令牌，核验频道后用接收方公钥加密。对象存储仅保存加密结果；解密私钥留在接收方电脑。领取并在本机验证成功后删除云端结果，不再需要传递文件。邀请有效期 48 小时，浏览器授权会话 10 分钟；过期记录不可领取，并在下次访问或维护清理时删除，当前没有定时物理删除保证。旧版加密文件交接方式仅供兼容，不应公开任何授权包或解密密钥。令牌持有人可在 Google 实际授予的范围内操作频道。

本地脚本不包含将上述数据出售、用于广告定位或训练通用 AI 模型的功能。如果另行使用 Codex 或其他助手处理资料，该服务的数据处理受其自身政策与组织设置约束。使用本工具取得的 Google 用户数据应遵循 Google API Services User Data Policy，包括 Limited Use 要求。

撤销和删除

可以在 Google 第三方连接撤销本应用授权。要删除本地记录、素材或授权副本，请删除相应文件和备份，并联系接收授权的指定同事删除其副本。撤销授权不会自动删除已上传的 YouTube 视频；需在频道中单独处理。

网站与联系

说明网站使用 GitHub Pages 托管，访问请求由 GitHub 按其隐私政策处理；这些静态说明页面没有自行加入分析脚本、登录表单或视频收集功能。另设的 频道授权服务由 Sites 提供运行环境与对象存储，其页面仅发起 Google 授权，不收集 Google 密码，也不提供视频上传入口。一般问题可通过 项目反馈联系维护者；涉及私密数据的请求应通过与维护者或指定同事已有的私下渠道沟通，不要在公开反馈中提交敏感内容。
